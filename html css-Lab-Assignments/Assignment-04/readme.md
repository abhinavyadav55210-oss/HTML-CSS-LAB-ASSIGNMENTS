Assignment 04 – Divs, Attributes and a Small Fix
Course: HTML and CSS Introduction Lab (BCS352)
Programme: B.Tech CSE – Second Year
University: Invertis University, Bareilly
Aim
Group parts of a page with div elements, add a data attribute, and fix the errors in a broken page.
Tasks
Task 1: Create Layout
File: layout.html
- Create three div blocks.
- First div should have class header.
- Second div should have class main.
- Third div should have class footer.
- Put some text inside each div.
Task 2: HTML Attributes
File: attributes.html
- Create one div with the id profile.
- Inside it, add one paragraph.
- Give the paragraph the attribute data-topic with the value hobbies.
- Write any text inside the paragraph.
Task 3: Fix the Broken HTML Page
File: attendance-fixed.html

Find and fix every error in the following HTML code:
<!DOCTYPE html>
<html>
<head>
<title>Attendance</title>
</head>
<body>
<h1>Attendance Report
<p>Asha: 92%<p>
<p>Rohan: 85%</p>
</body>
</html>


The corrected page should display:
- Heading: Attendance Report
- Asha: 92%
- Rohan: 85%
