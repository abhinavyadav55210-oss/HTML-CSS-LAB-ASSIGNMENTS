Aim
Link two pages together and add a picture with alt text.
Tasks
Task 1: Create Home Page
File: home.html
- Add an H1 heading: Welcome to My Site.
- Add a paragraph.
- Inside the paragraph, create a link to portfolio.html.
- Link text should be portfolio.
Task 2: Create Portfolio Page
File: portfolio.html
- Add a heading.
- Add a link back to home.html.
- Write any text for the link.
Task 3: Add an Image to Portfolio
File: portfolio-image.html
- Add a heading.
- Add a picture from the images folder.
- Set image width to 200.
- Set image height to 200.
- Add alt text describing the picture.
- Use the image filename provided by your instructor.
Files to Submit

- portfolio.html
- portfolio-image.html
- A screenshot of each page.
