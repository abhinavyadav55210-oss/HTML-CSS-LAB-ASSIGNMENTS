# Assignment 08 – Sign-Up Forms and Choices

**Course:** HTML and CSS Introduction Lab (BCS352)  
**Programme:** B.Tech CSE – Second Year  
**University:** Invertis University, Bareilly

## Aim
Make a labelled form with text, email and password fields, choices and a submit button.

## Tasks

### Task 1: Sign-Up Form
**File:** `signup.html`

- Create a form with `method="post"` and `action="thanks.html"`.
- You do not need to create `thanks.html`.
- Add labelled fields for:
  - Full Name
  - Email
  - Password
- Link each label to its respective input field.

### Task 2: Choices
**File:** `choices.html`

- Add a gender question with two radio buttons:
  - Female
  - Male
- Add a course dropdown with two options:
  - BCA
  - B.Tech
- Only one gender option should be selectable at a time.

### Task 3: Required Fields
**File:** `signup-required.html`

- Add a Full Name field.
- Add an Email field.
- Make both fields required.
- Add a placeholder to the name field.
- Add a Submit button.

## Files to Submit

- `signup.html`
- `choices.html`
- `signup-required.html`
