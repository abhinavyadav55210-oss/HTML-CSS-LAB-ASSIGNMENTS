Assignment 03 -- Your First HTML Page
Course: HTML and CSS Introduction Lab (BCS352)
Programme: B.Tech CSE -- Second Year
University: Invertis University, Bareilly
Aim
Write a first HTML page with a title, headings and a paragraph, and
format some text.
Tasks
Task 1: First HTML Page
File: first.html
- Create a valid HTML document structure.
- Set the page title to My First Page.
- Add one H1 heading: Hello, I am Asha.
- Open the page in a web browser and check the browser tab title and
  heading.
Task 2: Headings and Paragraph
File: headings.html
- Add one H1 heading.
- Add one H2 heading.
- Add one H3 heading.
- Add one paragraph.
- Write any text for the headings and paragraph.
Task 3: Text Formatting
File: text-format.html
- Add two paragraphs containing any text.
- Use <strong> on one word to make it bold.
- Use <em> on one word to emphasize it (usually displayed in
  italics).
- Add a line break (<br>) inside one paragraph.
Files to Submit
- first.html
- headings.html
- text-format.html
- A screenshot of each page.

How to Run
1. Open the assignment-03 folder in VS Code.
2. Open the required HTML file.
3. Right-click in the editor and choose Open with Live Server, or
   open the HTML file directly in a browser.
4. Take a screenshot of the page and save it in the screenshots
   folder.
