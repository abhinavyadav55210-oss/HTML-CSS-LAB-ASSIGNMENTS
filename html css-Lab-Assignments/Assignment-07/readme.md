# Assignment 07 – About Me Page

**Course:** HTML and CSS Introduction Lab (BCS352)  
**Programme:** B.Tech CSE – Second Year  
**University:** Invertis University, Bareilly

## Aim
Build a short About Me page with semantic tags, an about section and a contact link.

## Tasks

### Task 1: Create About Me Page
**File:** `about-me.html`

- Create a `<header>` containing:
  - An H1 heading with your name.
  - A `<nav>` with two links:
    - About → `#about`
    - Contact → `#contact`
- Add an empty `<main>` element.
- Add an empty `<footer>` element.

### Task 2: Add About Section

- Inside `<main>`, add a `<section>` with the id `about`.
- Add an H2 heading: `About me`.
- Add one paragraph about yourself.

### Task 3: Add Contact Link

- Inside `<footer>`, add a paragraph.
- Add a clickable email address using the `mailto:` link.
- Give the footer the id `contact`.
