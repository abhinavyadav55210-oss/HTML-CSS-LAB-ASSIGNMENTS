# Assignment 06 – Types of HTML Lists

**Course:** HTML and CSS Introduction Lab (BCS352)  
**Programme:** B.Tech CSE – Second Year  
**University:** Invertis University, Bareilly

## Aim
Make a bulleted list, a numbered list with a nested list, and a description list.

## Tasks

### Task 1: Shopping List
**File:** `shopping-list.html`

- Add an H1 heading: `Shopping List`.
- Create an unordered list using `<ul>`.
- Add three items:
  - Notebook
  - Pen
  - Bag

### Task 2: Canteen Menu
**File:** `canteen-menu.html`

- Add an H1 heading: `Canteen Menu`.
- Create an ordered list using `<ol>`.
- Add two items:
  - Samosa
  - Sandwich
- Under Sandwich, add a nested ordered list with:
  - Cheese
  - Vegetable

### Task 3: FAQ
**File:** `faq.html`

- Create a description list using `<dl>`.
- Add two questions using `<dt>`:
  - How many books can I borrow?
  - Is the library open on Sunday?
- Write an answer for each question using `<dd>`.
